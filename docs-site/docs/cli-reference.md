# SynapseStack CLI Reference

This page covers usage examples and command explanations for the SynapseStack CLI.

## Commands

```bash
npx tsx src/cli/rag-cli.ts init
npx tsx src/cli/rag-cli.ts run
npx tsx src/cli/rag-cli.ts benchmark
npx tsx src/cli/rag-cli.ts visualize --output graph.md
npx tsx src/cli/rag-cli.ts generate-types
```

Refer to the `README.md` for full examples and output formats.
